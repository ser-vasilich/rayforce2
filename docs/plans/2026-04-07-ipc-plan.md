# IPC Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Single-threaded async IPC server/client with TCP transport, sync/async messaging, RLE/delta compression, and REPL integration.

**Architecture:** New `src/core/ipc.{h,c}` provides socket abstraction (epoll/kqueue/select), event loop, connection state machine, and compression. Builtins `hopen`/`hclose`/`hsend` in `src/ops/system.c`. Server mode via `-p PORT` flag in `main.c`, event loop integrated with REPL via shared fd polling.

**Tech Stack:** Pure C17, POSIX sockets + Winsock2, epoll (Linux) / kqueue (macOS) / select (Windows), existing `ray_ser_raw`/`ray_de_raw` from `serde.h`.

**Step 1: Write ipc.h header**

```c
#ifndef RAY_IPC_H
#define RAY_IPC_H

#include <rayforce.h>
#include "store/serde.h"

/* ===== Socket Abstraction ===== */

#ifdef _WIN32
  typedef intptr_t ray_sock_t;
  #define RAY_INVALID_SOCK ((ray_sock_t)-1)
#else
  typedef int ray_sock_t;
  #define RAY_INVALID_SOCK (-1)
#endif

ray_sock_t ray_sock_listen(uint16_t port);
ray_sock_t ray_sock_accept(ray_sock_t srv);
ray_sock_t ray_sock_connect(const char* host, uint16_t port, int timeout_ms);
int64_t    ray_sock_send(ray_sock_t s, const void* buf, size_t len);
int64_t    ray_sock_recv(ray_sock_t s, void* buf, size_t len);
void       ray_sock_close(ray_sock_t s);
ray_err_t  ray_sock_set_nonblocking(ray_sock_t s);

/* ===== Compression ===== */

#define RAY_IPC_COMPRESS_THRESHOLD 2000

/* Returns compressed size, 0 if not worth compressing */
size_t ray_ipc_compress(const uint8_t* src, size_t len,
                        uint8_t* dst, size_t dst_cap);
size_t ray_ipc_decompress(const uint8_t* src, size_t clen,
                          uint8_t* dst, size_t dst_len);

/* ===== Connection State ===== */

#define RAY_IPC_PHASE_HANDSHAKE 0
#define RAY_IPC_PHASE_HEADER    1
#define RAY_IPC_PHASE_PAYLOAD   2

#define RAY_IPC_MAX_CONNS 256

typedef struct ray_ipc_conn {
    ray_sock_t        fd;
    uint8_t*          rx_buf;
    size_t            rx_len;       /* bytes received so far */
    size_t            rx_need;      /* bytes needed for current phase */
    uint8_t           phase;
    ray_ipc_header_t  hdr;          /* current message header */
} ray_ipc_conn_t;

/* ===== Server ===== */

typedef struct ray_ipc_server {
    ray_sock_t        listen_fd;
    int               poll_fd;       /* epoll/kqueue fd (-1 on Windows) */
    ray_ipc_conn_t    conns[RAY_IPC_MAX_CONNS];
    uint32_t          n_conns;
    bool              running;
} ray_ipc_server_t;

ray_err_t ray_ipc_server_init(ray_ipc_server_t* srv, uint16_t port);
void      ray_ipc_server_destroy(ray_ipc_server_t* srv);

/* Poll for events. timeout_ms: -1=block, 0=nonblocking, >0=wait ms.
 * Returns number of events processed. */
int       ray_ipc_poll(ray_ipc_server_t* srv, int timeout_ms);

/* ===== Client ===== */

/* Connect to server, perform handshake. Returns handle (>= 0) or -1. */
int64_t   ray_ipc_connect(const char* host, uint16_t port);

/* Close client connection */
void      ray_ipc_close(int64_t handle);

/* Send sync message, wait for response. Caller must release result. */
ray_t*    ray_ipc_send(int64_t handle, ray_t* msg);

/* Send async message (fire-and-forget) */
ray_err_t ray_ipc_send_async(int64_t handle, ray_t* msg);

#endif /* RAY_IPC_H */
```

**Step 2: Write socket functions in ipc.c**

Cross-platform TCP socket operations. Reference RF1 `sock.c` for the pattern but use Rayforce2 conventions (ray_ prefix, ray_err_t returns, ray_sys_alloc).

Key functions:
- `ray_sock_listen`: `socket` + `setsockopt(SO_REUSEADDR)` + `bind` + `listen`
- `ray_sock_accept`: `accept` + set `TCP_NODELAY`
- `ray_sock_connect`: `getaddrinfo` + `socket` + `connect` with timeout
- `ray_sock_send`: loop until all bytes sent (handle `EINTR`/`EAGAIN`)
- `ray_sock_recv`: single `recv` call, return bytes read
- `ray_sock_set_nonblocking`: `fcntl(O_NONBLOCK)` on Unix, `ioctlsocket(FIONBIO)` on Windows
- Windows: `WSAStartup`/`WSACleanup` in init/destroy

```c
#endif
```

`ray_ipc_server_init`:
- Create listening socket via `ray_sock_listen`
- Set non-blocking
- Linux: `epoll_create1(0)`, `epoll_ctl(ADD, listen_fd, EPOLLIN)`
- macOS: `kqueue()`, `kevent(EV_ADD, EVFILT_READ, listen_fd)`
- Windows: no poll_fd needed, use `select()` in `ray_ipc_poll`

**Step 2: Implement `ray_ipc_poll`**

The core event loop iteration:

```c
int ray_ipc_poll(ray_ipc_server_t* srv, int timeout_ms) {
    /* Platform-specific wait for events */
    /* For each ready fd:
     *   - listen_fd → accept new connection, add to conns[], set phase=HANDSHAKE
     *   - client fd → read into conn->rx_buf, advance state machine:
     *     HANDSHAKE: read version byte, validate, send response, switch to HEADER
     *     HEADER: read 16 bytes into conn->hdr, switch to PAYLOAD
     *     PAYLOAD: read hdr.size bytes, process message:
     *       - deserialize (decompress if flags & 1)
     *       - eval (string → ray_eval_str, list → ray_eval, other → ray_eval)
     *       - if sync: serialize result, send with msgtype=RESP
     *       - switch back to HEADER phase
     *   - error/hangup → close connection, remove from conns[]
     */
}
```

**Step 3: Integrate event loop with REPL**

In `repl.c`, the interactive REPL loop currently blocks on terminal input. Modify to:

- **TTY mode**: use the platform poll fd. Add stdin (fd 0) to the same epoll/kqueue set. When stdin is ready, process REPL input. When IPC sockets are ready, process IPC.
- **Non-TTY mode**: alternate between reading stdin lines and polling IPC with short timeout.

The key change in the REPL input loop: replace the blocking `read(0, ...)` with a poll that watches both stdin and IPC:

```c
/* In run_interactive / run_piped: */

    /* On Windows: use select() with both sets */
}
```
